# ARIS 科研工作流定制

本 fork 保留 ARIS 的 Skill 职责划分和 fan-out、评审、实验工件能力，加入本项目的两轮五集合、证据来源区分、Insight 卡、品味校准、H/Q/M/B/E 和 Notion 语义规则。

研究与实验配置分别见 [[profiles/research.tsv|研究 profile]] 和 [[profiles/experiment.tsv|实验 profile]]。profile 只描述可选能力，是否执行实验仍由当前任务授权决定。

跨阶段规则见 [[skills/skills-codex/shared-references/research-methodology-cn.md|科研方法论]]；Notion 语义入口见 [[skills/skills-codex/notion-research/SKILL.md|notion-research]]；方案到代码的只读衔接见 [[skills/skills-codex/research-implementation-plan/SKILL.md|research-implementation-plan]]。

本 fork 不保存私人 Notion 页面映射、凭据、未发表内容或具体科研仓库代码。日常使用时，将 fork 作为 ARIS 能力来源，再按项目选择 profile 安装。
