# 定制科研方法论

关键判断区分论文明确内容、跨论文归纳和本文推导。两轮检索分别形成问题、已有方法、明确局限/现象、假设与机制线索、可验证机会五集合；第二轮围绕第一轮未解问题定向检索。

Idea 先形成 Insight 卡：问题、证据类型、新认识、最强替代解释、可区分预测、最小验证、最近邻和风险。起步从 4--6 个相关 Lens 生成候选，子 Agent 只读，主 Agent 去重和统一写回。评分组织讨论，不能单独宣布科学成立。

每个核心假设 H 必须绑定直接验证实验；工程前置检查要单独标记。想 Idea、查新、精炼和实验计划默认不运行 pilot、不部署、不修改科研源码，实验须有当前任务的明确授权。
