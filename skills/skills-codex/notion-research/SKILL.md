# Notion 科研库工作方式

本 Skill 负责科研语义，Notion MCP 负责实际连接。当前任务先确认工具、权限和目标根页面；连接不可用时明确报告，不能把本地完成当成已同步。

## 内容归属

- 文献库保存五集合、原文/PDF、论文汇报、真实阅读和复现状态。
- Idea 与验证库保存一个 Idea 的方案、计划、中间实验、当前判断和版本历史。
- 实践经验库只在一个 Idea 的实验周期结束后保存最终复盘，并建立“经验”和“完整实验报告”页面。

不按单个 seed 或单次实验新建长期记录，不擅自改数据库 schema、字段名称或页面层级。

## 读取

按当前任务范围读取相关页面的完整分页，优先复用已有精读和页面 ID；关键判断回到论文原文或附件核对。记录页面 ID、读取时修改时间和方案版本。并行子 Agent 默认只读，返回带来源的分析。

## 写回

主 Agent 统一写回。写入前重新检查页面变化，按页面 ID 局部合并；保留评论、附件和历史。里程碑版本按现行约定归档旧稿，普通局部修订不制造重复页面。写回失败必须显式记录失败原因和未同步状态。

## 阶段边界

阶段开始读取，里程碑写回，修订时检查变化。不建设实时双向同步服务。长期知识以 Notion 为权威，代码、配置和原始实验产物以本地项目为权威。
